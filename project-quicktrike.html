Academic Project

QUICKTRIKE

Overview

QuickTrike is a high-fidelity UI/UX prototype designed to modernize eco-friendly local transportation. It addresses the accessibility gap in sustainable transit by connecting passengers and e-trike drivers through a seamless, mobile-first interface optimized for quiet, green, and efficient urban commuting.

The Design Challenge

The primary challenge was designing for a diverse user base. I had to ensure the interface was intuitive enough for e-trike drivers who may have limited tech experience, while maintaining a modern, efficient booking flow for commuters.

Key UX Features

  • ▹ One-Tap Booking Simplified location selection to minimize cognitive load.
  • ▹ Dual Dashboards Distinct, high-contrast interfaces for both Passenger and Driver modes.
  • ▹ Transparent Fare System Real-time distance-based pricing to ensure fair transactions.
