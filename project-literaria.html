Capstone Project

LITERARIA

Description

Literaria was developed to address the declining reading comprehension rates among students. As a Capstone project, the goal was to create an adaptive reading literacy platform that gamifies and enhances pupil's engagement in reading while providing teachers with real-time data on student progress. The main technical challenge was creating an "Adaptive" system—meaning the difficulty of the text and quizzes needed to change based on the student's previous performance in real-time. Integrating text-to-speech (TTS) and speech-to-text (STT) APIs to enable the Read-Aloud feature posed significant hurdles, especially in ensuring accurate reading assessment.

Key Features

  • ▹ Leveled passages for differentiated reading instruction.
  • ▹ Read-Aloud feature where students read the text aloud and system checks for fluency and accuracy
  • ▹ Gamified rewards and badges to boost student engagement.
