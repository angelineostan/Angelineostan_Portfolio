Academic Project

SweetBites

Overview

SweetBites is a vibrant, front-end discovery platform built to showcase local bakeries and their unique offerings. The goal was to create a visually appetizing and user-friendly directory that simplifies how users find specialty sweets in their area.

The Challenge

The focus was on creating a highly responsive and performant interface that handles large, high-resolution food imagery without compromising load times. I focused heavily on UI/UX principles to ensure the browsing experience felt as delightful as the products themselves.

Key Features

  • ▹ Modern, mobile-first responsive layout built with Bootstrap.
  • ▹ Intuitive bakery categorization and menu filtering.
  • ▹ Interactive image galleries and menu modals.
